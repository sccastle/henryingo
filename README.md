# Henryingo v20 — 读音拆分版

## 更新 GitHub Pages

1. 解压更新包，将本目录里的 9 个文件上传到原来放 index.html 的目录，覆盖同名文件。不要把外层文件夹作为新子目录上传。
2. 提交更改，等待 GitHub Pages 部署完成。
3. 打开原网址并刷新，左上角应显示 v20。如仍显示 v18，关闭所有 Henryingo 页面再打开，或在设置中检查更新。

## 本次改动

- 背词中文释义放大；增加彩色读音块和对应音标。
- classmate 支持 class → mate → classmate 顺序朗读和高亮。
- name 保留一个音节，纠正原 AI 提示中的 na + me。
- 新录入、重新分析的单词可保存 AI 返回的音标；未知单词不自动编造拆分。
- 内嵌分段合成音频：welcome 的 come、teacher 的 er 等可单独播放，不再回退为整词。分段音频为合成音，音色可能与系统整词语音不同；未知音节缺少音频时禁用分段按钮。
- 更新离线缓存至 v20；联网优先获取最新页面。

## 使用说明

首页的体验入口提供 classmate、welcome、teacher、monkey、bedroom、name 示例，不写入个人词库。
原网站的词库和设置仍保存在同一浏览器、同一网址的本地存储中；更新不清除这些数据。
本地预览文件中的词库不会自动同步到网站，可用「管理词库」中的导出、导入迁移。
朗读依赖设备英语语音；DeepSeek 功能需要网络和自己的 API key。未验证所有安卓设备音色。
